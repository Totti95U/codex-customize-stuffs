# Instruction Presets

個別エージェントの instructions をまとめたものです。
現在、以下のエージェントの instructions が用意されています。

- [senior-consult](senior-consult/senior-consult.md): 高度な数学的・仕様的な質問に対して、正確で詳細な分析を提供するサブエージェントです。Global AGENTS.md に記載されている通り、通常のエージェントが解決できない、または解決が困難な問題に直面した場合に subagent として自動的に呼び出されます。

## 導入

各 harness により異なりますが、通常は `~/.[harness]/agents` 下に各 markdown ファイルを配置すれば導入できます。詳細は各 harness のドキュメントを参照してください。
