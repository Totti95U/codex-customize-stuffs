# Toe Toe Recipe

## Character

- 全体はマリオ3に出てくるブーツにみたいな靴のくるぶし辺りに羽が二枚生えているシルエット
- つま先にかわいらしい目が2つついている。
- 口は明示的にはないが、ソールとつま先の境目が口っぽく見える
- 靴は植木鉢のようにもなっていて、靴の中には土が詰まっている
- 土からちょっとした植物が生えている

## Motion

| Codex state | 意味 | このキャラなら |
| --- | --- | --- |
| idle | 暇・通常状態 | 葉がふわふわ揺れる、瞬き、鉢が呼吸するように上下 |
| running-right | 右へ移動 | 黒い足がトコトコ動く＋羽を軽く羽ばたかせる |
| running-left | 左へ移動 | 上の左右反転。ただし葉やハイライトは必要なら描き分け |
| waving | 挨拶・クリック反応 | 片方の羽を手のようにパタパタ振る |
| jumping | ジャンプ・リアクション | 黒い足を縮める→ぴょん→羽を1回バサッ→着地 |
| failed | 処理失敗 | 鉢がぐらっと傾く、葉がしおれる、目がぐるぐる |
| waiting | ユーザー待ち | 左右をキョロキョロ、羽をもじもじ、葉を揺らす |
| running | Codex が作業中 | 足を高速で動かす／羽を高速羽ばたき。「一生懸命働いてる」感じ |
| review | 確認・review 中 | 少し前のめりになり、目を細めてじーっと見る |
| sleep | 長時間操作がない、夜間などの睡眠状態 | 目を閉じる → 羽を体の横に畳む → 葉が少し垂れる。鉢全体をゆっくり上下させて寝息っぽくする。たまに葉がピクッと動くと生き物感が出る |
| wake | sleep から通常状態へ戻る | 葉が先にピクッと立つ → 片目を開ける → 両目を開く → 羽を大きく伸ばす。「植物が朝日を浴びて開く」感じを混ぜる |
| sit | 移動を止めて休憩している状態 | 黒い足を少し潰して鉢を低くし、羽を床につける。目はぼんやり。葉だけが風で左右にゆっくり揺れる。デスクトップ上で一番長く見る idle variation |
| walk | デスクトップ上を自発的に移動 | 黒い足をキャタピラのように波打たせ、鉢を上下に少しバウンド。左右の羽を歩行に合わせて交互に振る。葉は本体より少し遅れて揺れると慣性が出る |
| land | ジャンプ・落下・ウィンドウ移動後の着地 | 接地直前に羽を広げる → 着地で黒い足と鉢が一瞬つぶれる → 葉が大きく上下に揺れる → 元に戻る。軽い dust 表現を入れても合う |
| drag | ユーザーが pet をドラッグしている | マウスでつまみ上げられたように足を浮かせる。羽をバタバタ、目をカーソル方向に向ける。高速で動かされたら葉が進行方向と逆に大きくなびく |
| petted | クリックや撫で操作に対する反応 | 目を細める／閉じる、羽を少し持ち上げる、葉を嬉しそうに左右へパタパタ。数秒撫で続けると鉢全体が小刻みに弾むくらい喜ばせてもかわいい |
| hover | マウスカーソルが近くに来た状態 | まず目だけカーソルを見る。少し近づいたら葉もそちらへ傾く。さらに近づいたら片方の羽を少し上げる。「気づいたけどまだ何もしていない」程度に抑える |
| climb | ウィンドウ端などをよじ登る | 羽で縁をつかむ → 黒い足を交互に蹴る → 鉢を少しずつ引き上げる。最後に黒い足が縁を越えて land へ遷移。葉が上下に激しく揺れると頑張っている感じが出る |
| fall | 高いところから落下中 | 目を見開く → 羽を最大まで広げてバタバタ → 黒い足を縮める。葉は上方向へ強くなびく。低速なら優雅、長距離ならだんだん焦る2段階にしても面白い |
| happy | 特定イベント成功・ユーザーとの良い interaction | 目を閉じてニコニコ → 両羽を大きく広げる → その場で一回転または小ジャンプ。葉を左右交互に大きく振る。このキャラの「最大喜びモーション」にする |

## Constraints

- 背景は透明
